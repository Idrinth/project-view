# Project View - notes for Claude

A small application that allows sharing multi-project progress with the world.

## Directory layout

```
bin/         PHP entry points for cronjobs, CLI tasks and tooling
public/      Web root - only contains built, directly servable assets
resources/   Source for HTML, CSS and JS (unminified, human-edited)
src/         Backend PHP source for the API that handles the data
```

### `bin/`
Every file is a standalone PHP script meant to be invoked from the command
line (via cron or manually). Nothing in here is reachable over HTTP.

- `bin/build.php` - reads `resources/` and writes a minified copy to
  `public/`. Run with `php bin/build.php`.

### `public/`
The web server's document root. Only built assets live here; there must be
no PHP or build-time code in this directory. The contents are generated by
`bin/build.php` and are gitignored (except for a `.gitkeep` marker).

Folder layout under `resources/html`, `resources/css`, `resources/js` is
flattened when copied into `public/` so references like
`<link href="style.css">` resolve directly.

### `resources/`
Unminified sources. Organised by asset type:

- `resources/html/` - page templates
- `resources/css/` - stylesheets
- `resources/js/` - client-side scripts

Edit files here, then run the build to publish them.

### `src/`
Backend PHP code for the API that reads and writes project data. This is
where models, controllers and service classes live. It is not part of
the document root; the API is exposed via a thin front controller in
`public/` once implemented.

## Current pages

Static HTML scaffolding only - no real data, no JS behaviour yet.

- `index.html` - overview / landing page with links to the three views
- `kanban.html` - three-column board (Todo / In Progress / Done) with
  placeholder cards
- `roadmap.html` - vertical timeline of upcoming milestones
- `time.html` - table of tracked hours per day and task category

## Build

```
php bin/build.php
```

The build:
1. Clears everything in `public/` except dotfiles.
2. Walks `resources/`, minifying `.html`, `.css` and `.js` files.
3. Writes the result flat into `public/` (the `html/`, `css/`, `js/`
   subfolders are stripped from the target path).

The minifier is intentionally small and lives entirely inside
`bin/build.php`; there are no third-party build dependencies.

## Conventions

- Keep `public/` free of source code - only built output.
- Do not reach across layers: frontend talks to the backend over HTTP
  endpoints defined in `src/`, never by including PHP files from
  `public/`.
- Anything that needs to run on a schedule or from the shell goes in
  `bin/`.
